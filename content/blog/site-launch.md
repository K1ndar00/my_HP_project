## はじめに

ずっと作りたかったパーソナルサイトをついに公開しました！

Next.js と Tailwind CSS を組み合わせて、思ったより短期間で形にできました。Markdown ファイルをリポジトリに追加するだけで記事が公開される仕組みが気に入っています。

## 制作を通じて学んだこと

- Next.js App Router の Server Components 活用
- Tailwind CSS v4 の新しい設定方法
- `gray-matter` を使った Markdown メタデータの取得

## 今後やりたいこと

- 検索機能の追加
- RSS フィードの対応
- OGP 画像の自動生成

少しずつ育てていきたいと思います。
